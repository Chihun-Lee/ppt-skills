# ppt 보고용 모드 — 발표자 없이 읽히는 보고자료

`SKILL.md`(발표용)와 **엔진·틀·기준서·게이트를 모두 공유**한다. 먼저 `SKILL.md`의 절차·API·시각 점검 항목을 따르고, 이 문서의 차이만 더한다.

- 엔진 모드: **`Deck("report", workdir=HERE)`** — 크기·글자량 토큰이 자동으로 바뀐다
- 기준서: `<스킬>/STANDARD.md` (보고용 수치는 §4.2·§5.2·§8의 /ppt_report 열)
- 쓰는 때: 결과보고, 검토자료, 발표 리뷰처럼 **발표자 없이 읽혀야 하는 덱**

## 한 줄 정의

> **보고자료 = 발표자 없이 읽혀도 이해되는 덱. 문장을 늘리는 게 아니라 요지·수치·표·캡션·인용을 빠짐없이 둔다.**

## 1. 발표용과 다른 점

| 항목 | 발표용 `Deck("ppt")` | **보고용 `Deck("report")`** |
|---|---|---|
| 크기 | 요지 24 / 세부 20 / 캡션·표 16 | **요지 20 / 세부 16 / 캡션·표 14** (제목 28 같음) |
| 요지 | 장당 1줄, 짧은 이름표 | **장당 3줄까지, 짧은 정량 사실**(요약·결론 장 5줄) |
| 세부 | 4줄, 항목당 1줄 | **6줄, 항목당 2줄까지**(균형 분할, 고아 줄 금지) |
| 글자량 | 서술 ≤ 140, 보이는 글자 ≤ 250 | **서술 ≤ 280(경고 220), 보이는 글자 ≤ 300(경고 260)** |
| 목차 | 10장 이상이면 | **필수**. 요약·References는 `front`·`back` 항목 |
| 결과 요약 장 | 선택 | **필수** — 목차 다음, `kind="summary"` |
| 간지 | 챕터 3개 이상이면 | **챕터마다 + 진행 표시** `d.divider(n, 이름, chapters=CH)` |
| 본문 배치 | 글+그림 좌우 우선 | **위 글·아래 그림 기본**(통일성). 반복 경고 없음 |
| 근거 | 권장 | **본문 장마다 그림·표 1개 이상** |
| 인용 | 장 하단 출처 줄 `s.source()` | **출처 줄 없음.** 캡션·본문 끝 `[n]` + 마지막 References |
| 감사 장 | 기본 | 생략 |
| 산출물 | `<덱 폴더>/output/` | 같음 + `<이름>_미리보기.pdf` |

## 2. 구성 골격

```
표지 → 목차 → 결과 요약 → (간지 → 본문 N장) × 챕터 → 결론·향후 일정 → References
```
- 장 수 기본값: 결과 1건당 1~2장, 본문 20장 이내. 넘으면 부록 챕터로 뺀다(사용자 지시가 있으면 따른다).
- 발표 리뷰(외부 발표를 보고 정리)면 표지 다음에 **연사 1인 소개** 장: 사진·소속·연구실·Google Scholar 지표.
- 특정 논문이 바탕이면 **논문 구성(서론→방법→결과→논의)을 챕터로 따라가고**, main figure를 추출해 인용한다(`pdfimages` 또는 `pdftoppm -r 200` 후 패널 단위 크롭). 캡션은 `<Fig. 3 공정 창 지도 [1]>`, References에 서지.

## 3. 요지와 문안 (보고용 강화)
- 요지(■)는 **정량 사실**: 대상 + 수치·단위 + 결과. 예: "재시험 6시편, 보정값과 오차 ±5% 이내". 슬로건·은유 금지. **짧게**(한 줄 30자 안팎, 수치 1~2개), 날짜(월/일)·→ 연쇄·괄호 나열 없이. 나머지 수치는 세부·표로.
- 세부는 결과 위주 쉬운 말, 현황은 `102개 중 102개 완료`처럼 개수로. 작업 날짜는 일정 장·표의 일정 열에만.
- 본문 장마다 네 가지를 채운다: 대상, 방법(조건·수치), 결과(값+단위, 표·그래프), 근거(그림·표·인용). 하나라도 비면 근거를 채우거나 장을 합친다.
- 검증 안 된 수치는 쓰지 않는다. 부득이하면 `(추정)`.
- 날짜·시각과 불리한 숫자(지연 경과, 실패 건수, 범위의 나쁜 쪽 끝값)는 굳이 쓰지 않는다. 빼는 것이지 값을 바꾸는 것이 아니다. 괄호(라벨, 풀이, 나열)를 줄인다.
- 내부 자료(자체 데이터·계획서)는 인용 번호를 달지 않는다. References에는 논문·외부 자료만.
- 언어: 한국어 기반 + 기술어 영어 원어. 전체 영어는 사용자가 요청할 때만.
- 나머지는 SKILL.md 8절과 같다(명사 종결, 콜론·대시·금칙어, 약어, 굵게·색 강조 금지).

## 4. 예시

```python
import sys; sys.path.insert(0, r"<스킬>/lib")      # ← 실제 절대경로로 바꾼다
from pathlib import Path
from kims_ppt import Deck

HERE = Path(__file__).resolve().parent
A = HERE / "assets"
CH = ["배경", "결과", "계획"]
d = Deck("report", workdir=HERE)
d.cover("스크랩 분류 모델 임곗값 비교", "○○과제 보고 2026.11", ["○○기관 ○○연구본부", "홍길동 선임연구원"])
d.toc([("배경", ["데이터 현황"]), ("결과", ["임곗값 비교"]), ("계획", ["향후 일정"])],
      front=["결과 요약"], back=["References"])

s = d.slide("결과 요약", kind="summary")
s.bullets([("임곗값 0.35에서 mAP50 0.87, 누락 12% 감소", ["검증 1,240장 기준", "오검출 3.1%에서 2.4%로 감소"]),
           ("라벨 재검수 대상 186장 확정", ["경계 모호 121장, 혼합 65장"])])
s.table(["임곗값", "mAP50", "누락률", "오검출"],
        [["0.25", "0.83", "18%", "3.1%"], ["0.35", "0.87", "12%", "2.4%"], ["0.45", "0.85", "15%", "2.0%"]])

d.divider(1, "배경", chapters=CH)
s = d.slide("데이터 현황", chapter=1)
s.key("검증 1,240장, 등급 5종 라벨")
s.text_figure([("등급별 분포 불균형", ["HMS1 41%, turnings 6%", "turnings는 증강 2배 적용"])],
              A / "grade_dist.png", "등급별 라벨 분포")        # 보고용은 위 글·아래 그림을 우선 고른다
# … 결과 챕터 …
d.divider(3, "계획", chapters=CH)
s = d.slide("향후 일정", chapter=3, kind="conclusion")
s.note("재검수 186장 반영 후 2차 학습")
s.timeline([("12월", "재검수 완료"), ("1월", "2차 학습"), ("2월", "현장 시험")], orient="h")
d.references(["Lee C. et al., Waste Management 170, 45 (2025)"])
d.save(HERE / "output" / "분류모델_보고.pptx")
```

- 모듈과 API는 SKILL.md 5·6절과 같다(`row`, `below`, `figures`, `table(fill=True)`, `cards`, `flow`, `timeline`, `note`).
- `s.source()`는 쓰지 않는다(보고용은 `[n]` + References).

## 5. 검토 2단계 (둘 다 통과해야 전달)

**Pass A: 레이아웃** — 발표용과 같다. `make.py` 게이트 fail 0, 시각 점검은 1회차 전 장 + 2회차부터 `review_state.py queue`가 내는 장만(경계는 `zoom.py`로 확대).

**Pass B: 내용·인용**
1. 본문의 모든 수치를 1차 출처(논문·실측 CSV·사진)와 대조한다. 없는 값은 지우거나 `(추정)`.
2. 본문 `[n]` ↔ References 순서·서지(저자·저널·연도·DOI/arXiv) 일치.
3. 목차 항목(앞·뒤 항목 포함) = 본문 제목 바 집합, 간지 진행 표시 = 현재 챕터.
4. 논문 기반이면 구성이 논문 구조를 따르고 인용 figure 번호가 맞는다.
5. 금칙어·추상어 0, 모든 본문 장에 근거(그림·표) 1개 이상, 요지가 정량 사실.

재감사는 **걸린 항목·고친 장만** 한다.

## 6. 전달
- `make.py`가 `output/<이름>.pptx` 옆에 `<이름>_미리보기.pdf`를 만든다. 이미 건넨 파일은 `_v2`, `_v3`로 새로 저장한다.
- PDF 쪽수 = 슬라이드 수를 확인하고 PDF를 사용자에게 열어 보여 준다.
- 보고: 경로, 장 수, Pass A/B 결과(반복 횟수·잡은 결함), 수치 충돌과 고른 값, 출처 주의점.

## 7. 완료 조건
1. ☐ 게이트 fail 0, 시각 점검(1회차 전 장 + 걸린 장·고친 장 재확인, 큐 0쪽)
2. ☐ 목차(앞·뒤 항목)·결과 요약·진행 간지·결론·References 존재
3. ☐ 본문 장마다 근거 1개 이상, 요지가 정량 사실
4. ☐ Pass B 5항목 통과
5. ☐ `output/`에 pptx + `_미리보기.pdf`, PDF를 사용자에게 보여 줌
